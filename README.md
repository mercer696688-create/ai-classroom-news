# AI Classroom News

用于课堂演示的 AI 数字主持人采访程序。打开公共链接后，页面本身就是学生看到的演示画面；程序采访 Miss Wu 三个固定问题，并按固定英文模板播报。

公共演示链接：https://mercer696688-create.github.io/ai-classroom-news/

## 启动

1. 用 Microsoft Edge 或 Chrome 打开公共链接。
2. 页面打开后直接显示数字人演示画面。
3. 鼠标左键前进，鼠标右键返回。
4. 第一次左键点击会同时解锁浏览器声音并开始开场。
5. 演示结束后停留在 `Thank you!` 和完整新闻总结；关闭网页即可结束。
6. 如果需要重新演示，在最终页面再点一次左键即可回到第一步。

## 现场使用

- 首次收音时允许浏览器使用麦克风。
- 数字人先问“May I ask you three questions?”；说完后会停下来，只有识别到 Yes、Yeah、Yep、OK 或 Sure 才开始 Question 1。
- 数字人说完问题后会自动开麦，并根据回答后的停顿进入下一题。
- 回答中短暂停顿会继续听；完整转写后停顿约 0.9 秒，只有半句或无转写时等待约 1.6 秒，避免老师还没说完就跳题。
- 文字转写用于辅助判断回答是否稳定，不要求包含 English、fun 或 Chinese。
- 新闻播报始终使用固定预设答案 English、fun 和 Chinese；复核页只展示识别文案，不能修改播报答案。
- 如果 Edge 没有及时返回文字，系统仍会按停顿立即继续，并以本题固定答案 English、fun 或 Chinese 作为记录兜底。
- 正常情况下 Miss Wu 正常回答即可；若识别没有推进，左键可以使用固定答案继续。
- 右键可以返回上一阶段并重新演示。
- 建议关闭电脑通知、使用外接麦克风，并在 Edge 设置中把本站麦克风权限设为允许。
- 老师新闻播报完成后，数字人会直接致谢并结束整场活动。
- 正式开始前确认电脑没有静音；第一次左键点击后应立即听到开场女声。
- 固定台词使用随程序提供的 Microsoft Zira 英文女声音频，不依赖 Edge 是否能加载系统语音列表。

## 投影舞台表现

- 待机：自然呼吸、随机眨眼和轻微眼神移动。
- 形象：女性 AI 主持人，长发、耳饰和蓝紫色主持人服装。
- 提问：抬眉、看向受访者并配合右手开放式手势。
- 等待回答：保持专注姿态，不会错误显示正在收音。
- 正在倾听：身体前倾、连续轻微点头，信号环切换为绿色。
- 准备播报：思考眼神和抬手动作。
- 新闻播报：正式站姿、双手交替手势，嘴型跟随实际声音；暂停时嘴型同步停止。
- 结束致谢：微笑、鞠躬和挥手，致谢朗读完成后进入最终页面。

建议投影使用 16:9 比例；已验证 1920×1080 和 1280×720。系统开启“减少动态效果”时会关闭舞台动画。

## 固定问题

1. What's your favorite subject?
2. Why do you like it?
3. What other subjects do you like?
